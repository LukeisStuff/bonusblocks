# Bonus Blocks

### Additions

## Blocks
* Box
  + Crafted with 9 planks


* Empty Bookshelf
  + Crafted like a bookshelf but without the books


* Branches
  + Crafted with 4 sticks
  + Crunchy


* 2 Leaves and saplings
  + Jacaranda Leaves
  + Mossy Oak Leaves
  + Jacaranda Sapling
  + Mossy Oak Sapling


* 4 Logs
  + Shrub Log
  + Cacao Log
  + Jacaranda Log
  + Scorched Log


* Overgrown Grasses
  + 6 sided grass blocks
  + Grass, Scorched Grass and Dirt Path variants
  + Crafted with 4 of each grass type


* 3 New Flowers and 1 New Mushroom
  + White Dandelion, Crafts into silver dye
  + Pansy, Crafts into light blue dye
  + Hyacinth, Crafts into magenta dye
  + Clovers, Crafts into lime dye
  + Each flower generates in different biomes, have fun exploring!
  + Gray Mushroom, Crafts into gray dye


* Petals
  + Petal block variant for every flower
  + includes a flower bed layer version


* Fungi Blocks
  + Red, Brown and Gray variants
  + Crafted with 4 of each mushroom


* Tons of new storage blocks
  + Bone
  + Cloth, bouncy like modern slime
  + Slime, sticky like modern honey
  + Sulphur, explodes like explosive charge
  + Sugar, dissolves in water
  + Leather
  + Raw Iron
  + Flint
  + Crude Steel


* Wicker
  + Crafted with 2 sticks and 2 leather
  + Decoration block that uses the basket texture


* Steel Changes
  + Steel is now split into 2 sets, crude and normal
  + Added Door and trapdoor versions of steel glass
  + Steel has a mesh block now, explosion proof and immovable


* Verdigris Ore
  + Drops 3-7 raw verdigris
  + Generates at any Y level in the nether


* Verdigris Blocks
  + All verdigris blocks can burn into their burnished variants
  + Block and brick variants
  + Stairs and Slabs
  + Trapdoor and Door
  + Fence and Mesh


* Polished Marble
  + Crafted in the same way as other polished stone blocks


* Carved Marble and Carved Slate
  + Crafted in the same way as other carved stone blocks


* Baked Clay
  + Made from smelting a clay block


* Obsidian Glass
  + Explosion proof, trapdoor variant


* Quartz Glass
  + More clear than normal glass
  + Crafted with 2 glass and 2 quartz


* Baked Dirt
  + Crafted by smelting dirt
  + Doesn't turn into grass


* Moss Block
  + Replaces mossy stones in generation
  + Converts blocks to mossy forms
  + Drops 4 moss clumps when mined


* Skull and Skull Lantern, Redstone Skull
  + Generates like pumpkins in the nether
  + Can be lit with a soulwax candle


* Soul Wax Candle and Soul Wax
  + Crafted with soul wax and string
  + Soul wax is made from smelting soul sand


* More Slabs
  + 12 blocks now have slabs to go along with them
* More Stairs
  + 10 blocks now have stairs to go along with them
* More Doors
  + 15 blocks now have doors to go along with them


* Steel Door and Steel Trapdoor
  + Work like iron versions but with full blast resistance


* Nuggets
  + Raw Iron, Raw Gold, Raw Verdigris and Flint can be placed on the ground like pebbles now


## Items
* Soul Wax Candle and Soul Wax
  + Soul wax is from smelting soulsand
  + Soul wax and string crafts a candle


* Raw Verdigris and Verdigris Ingot


* Verdigris Doors, Gold Door and Steel Door


* Gold Bed and Gold Seat


* Moss Clump
  + Obtained from mining moss blocks, 4 crafts into 1 moss block


## Biome
* Overgrown Meadow
  + Replaces the current meadow
  + All flowers generate there
  + Purple Jacaranda Trees grow here
  + Made of overgrown grass and limestone


## Changes
* Pillars now use a new recipe with 3 of the respective stone type instead of 2
* Carved stones now have recipes and appear in the creative inventory
* Multiple items and blocks have been given new names to address issues and fix bugs
* Pebbles now generate all over the world
* Some recipes missing have been fixed
* Cobbled Stone recipes in the blast furnace now use the stone instead of cobble
* Multiple Old blocks from previous bonus block versions have been removed in order to streamline the mod
* All Cacao, Shrub and Mossy Oak trees now generate with all of their own logs/leaves

## Requirements

+ BTA 7.3_04
+ Babric
+ Halplibe
